# die Ponytanten - Homepage
This repository contains the source code for the "die Ponytanten Homepage" - a small informational website presenting a pony-based childcare and activity program for children.

![alt text](https://github.com/olHannes/diePonyTanten/blob/main/static/images/page-startup.png?raw=true)
---
## About "die Ponytanten"

die Ponytanten offer childcare and recreational activities centered around ponies.
The goal is to create joyful, educational, and memorable experiences where children can interact with ponies in a safe and playful environment.

**Activities:**
- Pony rides and adventures
- Children's birthday events
- Workshops and playful learning with ponies
- Outdoor experiences in nature

## About the Website

The Website ``https://dieponytanten.de/`` serves as a simple homepage tha introduces the project and provides essential information.

It includes:
- Overview of the program
- Presentation of the team and ponies
- Image galleries showcasing activities
- Contact information and location
- Navigation through different sections (Home, Offer, About, Gallery, Contact)
